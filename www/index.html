$_helix
Helix's editing, unchanged. Every key you know still works; Helide adds the rooms around it.
$_file tree
Ctrl+1. Create, rename and delete in place, with code stats for the folder you are in.
$_git
Ctrl+2. Stage hunks, commit, branch and stash. A click opens a file's diff as a tab, tinted green and red.
$_terminal
Ctrl+4. Tabs and side-by-side panes that come back with the project.
$_agents
Ctrl+5. Claude Code or OpenCode in tabs that reopen on the same conversation. Space @ mentions the file you are in.
$_tabs per split
Each split keeps its own row of tabs. Drag them between rows, or onto an agent to type the path.
$_time travel
:history scrubs through every version you opened or saved; :history git through the commits.
$_persisted workspace
hx . brings back tabs, splits, panels, terminals and agents. hx file is just a quick edit.
