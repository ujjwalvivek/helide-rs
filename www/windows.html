$_the first helide
Helide began as a Windows app: helix, lazygit, yazi and PowerShell sessions in one keyboard-driven window. The Helix fork grew out of it, moving the same workspace inside the editor itself.
$_command palette
Ctrl+P reaches everything: projects, panes, themes, windows.
$_panes
Git and the file tree on Ctrl+1 and Ctrl+5, PowerShell on Ctrl+3, F11 for zen. OpenCode, Codex or Claude, whichever you have installed.
