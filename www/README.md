# www

The site at helide.ujjwalvivek.com: the landing page (index.html), the docs (docs.html), and
the WebGL background (background.glsl) in Noctalia's colours, with the glass rim drawn over the
window's border.

Screenshots live in images/: webp/ at 1920x1080 and thumbnails/ at 640x360, made from
docs/helide/ in the repo. images/windows/ holds the first Helide's, the Windows app.

Preview locally:

```sh
python -m http.server 8000 -d www   # then open http://localhost:8000/
```
